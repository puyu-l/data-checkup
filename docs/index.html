数据体检

给台账做一致性检查 —— 输入几个 CSV，输出一份能直接发给同事看的问题报告。

它解决什么问题

手工维护的台账，错的地方往往不是「算错了」，而是「没对上」：发票挂的合同号写错了、同一个单号录了两遍、 流水金额和发票差了一万、某个金额多打了一个零。

这些错误单看每一行都正常，只有交叉比对才能发现。这个工具把交叉比对写成规则，一次跑完。

怎么用

  • 纯 Python 标准库，不需要安装任何依赖
  • python checkup.py 检查自带示例
  • python checkup.py 我的数据目录 检查自己的数据
  • 终端输出摘要，同时生成单文件 HTML 报告

九条规则

  • 必填项缺失、单号重复、疑似重复记账
  • 引用不存在、时间倒置、日期格式不统一
  • 金额为负、超额开票、金额不符、疑似离群值

离群值用四分位距判断而非平均数 —— 一笔极端值会把平均数拉高，反而藏住它自己。
